# 🛒 Registro de Productos con JavaScript

Mini proyecto desarrollado en JavaScript como parte del módulo de **Métodos de Arreglos de DEV.F**.

## 📌 Descripción

El programa permite registrar productos con su nombre, precio y categoría, almacenándolos como objetos dentro de un arreglo.

Posteriormente, utiliza distintos métodos de JavaScript para filtrar, ordenar y consultar la información de los productos.

## ⚙️ Funcionalidades

- Registrar productos mediante `prompt()`.
- Almacenar productos como instancias de la clase `Producto`.
- Filtrar productos con precio menor a $100.
- Ordenar alfabéticamente los nombres de los productos.
- Obtener un arreglo con los precios de todos los productos.
- Mostrar los resultados en la consola del navegador.

## 🛠️ Conceptos utilizados

- Clases, constructores y objetos.
- Arreglos (`Array`).
- Funciones flecha (`=>`).
- Métodos `filter()`, `map()`, `forEach()`, `push()` y `sort()`.
- Ciclos `for`.
- Entrada de datos con `prompt()`.
- Template literals y `console.log()`.

## 💻 Tecnologías
